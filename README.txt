NEXORA DATAWORKS - SINGLE-FILE WEBSITE
======================================
index.html  = the complete website (design, scripts and logo are built in).

1. Double-click index.html to view it on your laptop.
2. To publish free: upload ONLY index.html to a new public GitHub repository,
   then Settings > Pages > Deploy from branch > main > /(root) > Save.
   (Or drag a folder containing index.html onto app.netlify.com/drop)
3. To edit: open index.html in VS Code. Replace "Your Name Here", the sample
   portfolio cards and the email address with your real details.
